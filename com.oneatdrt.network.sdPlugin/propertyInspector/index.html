Auto asks ipify for the IP each check and ipinfo.io for country and ISP only when the IP changes, which stays well inside ipinfo's free 50,000 requests a month. If a service fails, ipify and icanhazip are used for the IP.

Online/offline also uses pings to the default hosts (US, EU, RU).

HOSTS

Three hosts per page; turn the knob to page through. If a host doesn't answer ICMP ping but answers on TCP port 443, it's pinged over TCP from then on. Anycast addresses like 8.8.8.8 or 1.1.1.1 always answer from the nearest server, so they don't measure a region — use a host that lives there.
